# Flask Laboratory 5 — WTF Forms

## Встановлення залежностей

```bash
pip install -r requirements.txt
```

## Запуск застосунку

```bash
python run.py
```

## Запуск модульних тестів

```bash
python -m unittest discover -s tests -v
```

Контактна форма доступна за адресою `/contact`. Каталог товарів — `/product`.
Дані товарів зберігаються у `data/products.json`, а завантажені зображення — у `app/products/static/uploads/`.
